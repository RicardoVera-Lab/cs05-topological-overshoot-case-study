# Research Integrity Notes

The project adopted several safeguards that are visible in the repository.

## Pre-data freeze

The primary analysis logic was implemented and hashed before author-supplied real trajectory data were available.

## Negative-result preservation

Absorbed branches and blocked experiments are documented rather than removed from the narrative.

## No rescue by silent endpoint changes

The project did not shift the overshoot window, weaken the endpoint, or replace the required trajectory data with a different evidentiary object under the same experiment ID.

## No novelty by search failure

Failure to locate an exact prior-art match was not treated as proof of novelty.

## No hypothesis promotion by absence

H0, H1, and H2 all remain unresolved.

## Evidence-access stop

The investigation stopped when it reached an external data dependency that could not be satisfied at the required standard.
