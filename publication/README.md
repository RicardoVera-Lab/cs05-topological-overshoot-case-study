# CS05 publication package

This directory contains metadata for the first public technical-report release of CS05.

The publication artifact is versioned as **v1.0.0** and preserves the final scientific wording:

> **Unresolved due to unavailable external raw data. No mechanism claim made.**

The release assets are intended to include the publication-ready PDF, editable DOCX, Markdown source, bibliography records, metadata, and SHA-256 integrity hashes.

The public repository remains intentionally separated from the private master research archive. Proprietary internal research-system prompts, functional assignments, sequencing, routing logic, handoff formats, thresholds, decision authorities, and governance architecture are not part of this release.
